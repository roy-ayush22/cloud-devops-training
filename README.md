# Azure Cloud Training

This repository contains my hands-on Azure Cloud training tasks, covering **Virtual Machines, VNet Peering, IIS, Load Balancing, and Linux administration**.

## Tasks

* **Virtual Machines** — Created and configured two Windows Server VMs and hosted IIS web servers.
* **VNet Peering** — Established private connectivity between the two VNets and verified communication using `ping`.
* **Load Balancer** — Configured a Standard Azure Load Balancer with a frontend IP, backend pool, health probe, and load-balancing rule.
* **Linux Virtual Machine** — Deployed a Linux VM, connected via SSH, and performed basic server setup and validation.
